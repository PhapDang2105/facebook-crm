# Assets

- `branding/`: logo, màu sắc và tài liệu nhận diện.
- `icons/svg/`: icon vector ưu tiên dùng trong giao diện.
- `icons/png/`: icon raster hoặc bản chuyển đổi.
- `images/`: ảnh giao diện, minh họa và ảnh báo cáo.
- `fonts/`: font được cấp phép sử dụng nội bộ.
- `templates/`: mẫu báo cáo, dashboard, email hoặc import.
- `source/`: file thiết kế gốc có thể chỉnh sửa.
- `optimized/`: asset đã nén/tối ưu cho sản phẩm.
- `exports/`: file xuất hoặc bản bàn giao.

Không ghi đè file nguồn. Khi thay đổi asset quan trọng, thêm version vào tên file hoặc lưu lịch sử trong Git nếu dung lượng phù hợp.
