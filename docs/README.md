# Tài liệu kỹ thuật

- `architecture/`: sơ đồ hệ thống, quyết định kiến trúc và luồng dữ liệu.
- `data-model/`: data dictionary, entity relationship và quy tắc định danh.
- `api/`: API contract, webhook và quy ước lỗi.
- `security/`: RBAC, consent, retention, audit và xử lý sự cố.
- `operations/`: runbook triển khai, backup, phục hồi và giám sát.
- `roadmap/`: phạm vi MVP, backlog và kế hoạch phát hành.
